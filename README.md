# 美食模拟器 · 幸福小吃街

一个纯单文件网页小游戏（`index.html`），无需构建、无依赖，浏览器直接打开即玩。

## 核心循环

> **吃饭花钱，活着不易；做饭赚钱，续命全靠手艺。**

```
点菜开火 → 火候小游戏 → 出菜 → 卖出赚钱 / 自己吃掉
   ↓                              ↓
花钱买食材、耗体力耗饱食      赚来的钱用于下馆子续命
   ↓                              ↓
饱食度 ↓ 饱食见底 → 健康掉 → 健康归零 = 饿晕结算
```

## 玩法说明

### 活着（生存）
- **🍚 饱食度**：随时间持续消耗，做饭也额外消耗；归零后 **❤️ 健康开始流失**。
- **❤️ 健康**：归零即"饿晕"，游戏结束，结算存活天数、营业额、干饭次数等数据，可一键重开。
- 吃饱（饱食 > 70）时健康会缓慢回复。
- **📅 天数**：每 60 秒为一天，看看你能活到第几天。

### 吃饭（花钱续命）
- **吃自家菜**：免费，按菜的售价折算饱食，同时回 15 体力。
- **街口面馆（30 元）**：饱食 +50，体力 +20。
- **火锅大餐（100 元）**：饱食回满，体力 +40。

### 做饭赚钱（经营）
- 左侧菜谱点「开火烹饪」，进入**火候小游戏**：指针来回摆动，在**金色区**停下 = 完美出品（售价 ×1.35），绿色区 = 火候刚好，其余 = 勉强能吃（打折出售）。
- 高级菜谱速度更快、容错更窄，赚头也更大。
- **连续完美出品触发连击**，售价最高 +30%。
- 做菜获得经验，**升级解锁新菜谱**（白灼青菜 → 满汉全席共 10 道）。

### 胜利条件
- 累计营业额突破 **8888 元**，达成「美食街传奇」金字招牌（可继续玩）。

## 操作

- 鼠标：点菜开火，点「🔥 起锅！」收锅。
- 键盘：烹饪中按 `空格` 起锅。

## 技术说明

- 单 HTML 文件，内联 CSS/JS，无外部依赖。
- WebAudio 合成音效（无音频文件）。
- 本地双计时器驱动：2 秒一跳的生存结算 + requestAnimationFrame 火候指针。
